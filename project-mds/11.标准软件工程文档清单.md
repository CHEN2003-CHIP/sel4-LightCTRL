## 3. 数据库设计说明的处理原则

本项目是嵌入式控制系统，不包含传统数据库。为了满足软件工程文档流程，仍提供 `9.数据库设计说明书.md`，但其内容不是虚构数据库表，而是说明：

- 项目为什么不使用数据库。
- shared memory 如何承载运行期状态。
- transport message 如何承载跨域消息。
- fault state 如何由 `fault_mg` 统一管理。
- 测试证据如何以 `test-results/<run-id>/` 文件形式保存。

这种处理方式比强行编造数据库表更符合项目实际。
