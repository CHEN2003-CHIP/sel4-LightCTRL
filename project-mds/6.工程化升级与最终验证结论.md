# LightDemo 工程化升级与最终验证结论

## 1. 最终版本

当前最终交付版本为 **LightDemo Engineering Final v2.0**，验证运行编号为 `final-v2.0`，证据目录为 `test-results/final-v2.0/`。

## 2. 工程化升级内容

| 版本 | 升级内容 | 证据 |
| --- | --- | --- |
| v1.1 | 用 elapsed-time recovery window 替代纯 observation tick | `recovery_elapsed_ms` |
| v1.2 | 补齐 fault taxonomy：来源、等级、恢复策略、输出策略 | `FAULTMG_EVENT ... severity=...` |
| v1.3 | 自动归档 manifest、summary、QEMU log 和答辩报告 | `make evidence`, `make defense-report` |
| v2.0 | 扩展复杂车辆状态模型 | `gear`, `ambient`, `hazard`, `drive_mode` |

## 3. 代码结构升级

```text
src/domains/   Microkit protection domain 入口
src/core/      可 host-test 的核心逻辑
src/support/   支撑代码
include/       公共接口
systems/       Microkit system 描述
tests/         host-side 测试
scripts/       QEMU 和证据脚本
reports/       答辩展示材料
```
